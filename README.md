# Project HYDROS - Interactive 3D Visualization

🌊 An immersive 3D React/Three.js website showcasing the HYDROS (Hyperbaric Underwater Dissolved Oxygen Respirant Station) system.

## 🎮 Features

✅ **Interactive 3D Model** - Rotate, zoom, and inspect all 9 components  
✅ **Real-time Highlighting** - Click to highlight each system  
✅ **Detailed Specifications** - Engineering data for every component  
✅ **Animation Modes** - Visualize seawater flow, O₂ extraction, and gas circulation  
✅ **Dark Sci-Fi Theme** - Professional underwater aesthetic  
✅ **Fully Responsive** - Works on desktop and tablets  

## 🌊 Components Visualized

1. **🌪️ Turbines** (Cyan) - 3 axial-flow turbines drawing seawater
2. **🫧 Membrane** (Yellow) - Polysulfone hollow-fiber extraction chamber
3. **🧹 Scrubber** (Green) - CO₂ neutralization unit
4. **🔋 Buffer Tank** (Pink) - O₂ pressure storage
5. **⚡ Manifold** (Purple) - 6-diver gas distribution header
6. **🏗️ Frame** (Gray) - Structural support skeleton
7. **🔗 Hoses** (Blue) - Umbilical breathing circuits
8. **🟠 Emergency Tanks** (Orange) - Backup O₂ reserve
9. **🔵 Balloon** (Light Blue) - Buoyancy mooring system

## 🔧 Project HYDROS Overview

HYDROS is a conceptual engineering solution that extracts dissolved oxygen directly from seawater at 20 meters depth to supply 6 divers continuously through a closed-loop breathing system.

### Key Parameters

- **Operating Depth:** 20 meters
- **Divers Supported:** 6 simultaneous users
- **O₂ Demand:** 0.129 kg/hour
- **Membrane Area:** 3.47 m²
- **Seawater Flow:** 109,800 L/min (×73 safety margin)
- **Structural Safety Factor:** 3.32 (ASME compliant)
- **Emergency O₂ Duration:** 34 minutes
